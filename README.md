Azure Log Analytics is a service that helps you collect and analyze data generated by resources in your cloud and on-premises environments, providing query, management, and data collection APIs for monitoring and analytics.

**Areas:** Analytics · Microsoft Azure · Cloud · Logging · Monitoring

## Azure Log Analytics on APIs.io

Everything profiled for Azure Log Analytics is published on APIs.io rather than in this repository. Start at the provider page — **[apis.io/providers/azure-log-analytics/](https://apis.io/providers/azure-log-analytics/)** — or go straight to one of the APIs or properties below.

### APIs (5)

- [Azure Log Analytics Ingestion API](https://apis.io/apis/azure-log-analytics/azure-log-analytics-ingestion-api/) — Send log data to Log Analytics workspaces
- [Azure Log Analytics Query API](https://apis.io/apis/azure-log-analytics/azure-log-analytics-query-api/) — Execute KQL queries against Log Analytics workspaces
- [Azure Log Analytics Saved Searches API](https://apis.io/apis/azure-log-analytics/azure-log-analytics-saved-searches-api/) — Manage saved KQL queries
- [Azure Log Analytics Tables API](https://apis.io/apis/azure-log-analytics/azure-log-analytics-tables-api/) — Manage workspace tables
- [Azure Log Analytics Workspaces API](https://apis.io/apis/azure-log-analytics/azure-log-analytics-workspaces-api/) — Manage Log Analytics workspaces

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Azure Log Analytics: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
